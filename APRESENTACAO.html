USP Data Lake

Pipeline de Engenharia de Dados

Arquitetura, Implementação e Containerização

Visão Geral do Projeto

Objetivo Principal

  • Construir um pipeline de engenharia de dados completo
  • Processar conteúdo de múltiplas fontes (Jornal USP + PDFs)
  • Armazenar, transformar e vetorizar dados
  • Possibilitar buscas semânticas e análises avançadas

Stack Tecnológico

MinIO
Armazenamento (Bronze)
PostgreSQL
Banco Relacional (Gold)
Qdrant
Banco Vetorial (Gold)
Python
Orquestração & Processamento

Arquitetura - Camadas de Dados

Estrutura em 3 Camadas

📦 BRONZE LAYER (Raw Data) ├── 📄 JSON do Jornal da USP └── 📑 Arquivos PDF (novo requisito) ↓ 🔄 SILVER LAYER (Cleaned & Processed) ├── 🧹 HTML limpo para Markdown ├── 📋 Extração de texto de PDFs └── ✂️ Chunking (1200 caracteres / 200 overlap) ↓ ✨ GOLD LAYER (Business Ready) ├── 🗄️ PostgreSQL: Texto completo indexado └── 🔍 Qdrant: Vetores (embeddings BGE-M3)

Benefício da Separação

Clareza de responsabilidades, fácil manutenção, rastreamento completo dos dados

Fluxo de Dados Detalhado

📥 Etapa 1: Ingestão (Bronze)

Fonte 1 - Web Scraping

  • Coleta automática de notícias do Jornal da USP
  • Armazenamento em formato JSON

Fonte 2 - Upload de PDFs (NOVO)

  • Inserção manual de documentos em PDF
  • Suporte nativo e transparente

Destino

  • MinIO (armazenamento S3-compatível)
  • Prefixo: raw/

Fluxo de Dados - Transformação (Silver)

🔄 Etapa 2: Limpeza e Chunking

Entrada: JSONs e PDFs do MinIO

Processamento:

  • Extração de texto (HTML → Markdown para JSON)
  • Extração de texto para PDFs usando PyPDF2
  • Remoção de ruído (scripts, estilos, publicidades)
  • Divisão inteligente em chunks (1200 chars + 200 overlap)

Saída: Chunks estruturados em JSONL

Exemplo de Chunk

{ "documento_id": "usp_news_000001_001", "chunk_id": 1, "texto": "[conteúdo aqui]", "titulo": "...", "url": "...", "categoria": "Ciências" }

Fluxo de Dados - Armazenamento (Gold)

💾 Etapa 3: Carregamento em Gold

PostgreSQL (Texto)

  • Armazena chunks completos com indexação
  • Permite buscas por palavra-chave
  • Mantém rastreabilidade: documento_id, chunk_id, timestamps
  • Tabela chunks com constraints de integridade

Qdrant (Vetores)

  • Embeddings BGE-M3 (multilíngue, 384 dimensões)
  • Permite buscas semânticas (similaridade coseno)
  • Point ID = PostgreSQL ID (vínculo 1:1)
  • Payload armazena metadados

Resultado: Texto + Vetor sincronizados para buscas híbridas

Suporte a PDF - Novo Requisito

🎯 Integração com PDFs

Desafio Original: Pipeline era exclusivamente JSON

Solução Implementada:

  • Biblioteca PyPDF2 para extração de texto
  • Detecção automática de tipo de arquivo (.json vs .pdf)
  • Processamento transparente no pipeline existente
  • Metadados genéricos para PDFs

Fluxo Unificado:

PDF/JSON → Extrair Texto → Limpar → Chunking → Gold

Benefício: Reutilização de todo o pipeline para múltiplos formatos

Containerização com Docker

🐳 Arquitetura de Containers

docker-compose.yml ├── minio (container) │ └── API: 9000 | Console: 9001 ├── postgres (container) │ └── Conexão: 5432 ├── qdrant (container) │ └── API: 6333 └── app (container - NOVO) └── Python 3.12 + Dependências └── Pipeline Executável

Vantagens

  • ✓Isolamento de ambientes
  • ✓Reprodutibilidade garantida
  • ✓Fácil deploy em qualquer máquina
  • ✓Integração transparente entre serviços

Container App - Detalhes Técnicos

📦 Dockerfile do Pipeline

Camadas do Build:

  1. Base: Python 3.12 slim
  2. Dependências de sistema: gcc, libxml2, libxslt1
  3. Pip upgrade + Requirements (torch, pandas, transformers, etc.)
  4. Código-fonte copiado para /workspace

Vantagens:

  • Build reproducível bit-by-bit
  • Cache eficiente de dependências
  • Imagem otimizada (~2.5GB com torch+CUDA)

Execução:

docker compose run --rm app python src/transform.py --source local

Fluxo Operacional - Passo a Passo

1️⃣ Iniciar Infraestrutura

docker compose -f docker/docker-compose.yml up -d --build

→ MinIO, PostgreSQL, Qdrant, App prontos

2️⃣ Preparar Dados

  • Colocar JSONs em bronze/raw/
  • Colocar PDFs em bronze/raw/

3️⃣ Executar Pipeline

docker compose run --rm app python src/transform.py --source local --load-gold

4️⃣ Resultado

  • PostgreSQL: tabela chunks pronta
  • Qdrant: collection com vetores
